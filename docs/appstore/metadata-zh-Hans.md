```

## 描述

```
口袋课表是一款给大学生用的课表工具：把教务系统的课表导进来，之后每天只需要看一眼。

· 一键导入
支持从教务系统网页源码导入课表，也能手动添加、改教室、调周次。单双周、连堂课、同一时间不同周的不同课都能正确显示。

· 今天一屏看完
打开就是本周课表，当前周高亮，正在进行和下一节课单独标出来。左右滑动切换周次，长按可以快速跳周。

· 桌面小组件
小尺寸看「正在上课 / 下一节」，中尺寸列今天全部课程。最后一节下课后自动变成「今日课程已经上完了」，过了零点自动切换到新的一天。

· 数据都在本机
没有账号、不需要注册，课表只存在你自己的手机里，不会上传到任何服务器。

· 轻量、无广告
没有开屏广告，没有信息流，打开就能用。

说明：本 App 是学生自制的非官方工具，与任何高校及教务系统无隶属关系；课表数据由使用者自行导入，仅用于个人查看。
```

## 审核备注（App Review Information → Notes）

```

课表来源：用户在「导入」页粘贴教务系统课表网页源码，或手动添加课程；解析全部在本机完成，App 不上传任何数据，也没有服务端账号。
