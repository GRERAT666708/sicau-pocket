安装步骤

  1. 点上面的「下载 APK」，等浏览器下载完成（约 47 MB，流量党注意）。
  2. 下载完成后点通知或文件打开。系统可能提示"禁止安装未知来源应用"，在弹窗里选择设置 → 允许来自此来源，然后再点安装。
  3. 安装完成点「打开」。第一次启动会先放一份示例课表；校区和专业在「我的 → 设置」里改，它决定「空闲教室」默认落在哪个校区。
  4. 到课表页点顶部提示条的「去导入」，选「打开教务网并导入」，登录后进到课表页点底部「导入这个页面」，示例课表就被替换成你自己的了。

iOS 版本（TestFlight 内测）

iOS 版和安卓版是同一套代码（Expo + React Native），界面、课表、专注记录完全一致，数据同样只存在手机上。目前通过 TestFlight 分发，正式上架 App Store 需要等审核。

  1. 先装 TestFlight：在 App Store 搜「TestFlight」（Apple 官方出品，免费）并安装。
  2. 拿到邀请：TestFlight 是邀请制的，把 Apple ID 邮箱发给 wcy77416160@outlook.com，或等群里发的公开邀请链接，点开后选「接受」。
  3. 装 App：在 TestFlight 里点「川农口袋」→ 安装，装完直接打开就能用。
  4. 后续更新：以后有新版本，TestFlight 会推送提醒，点一下就能更新，不用重新找安装包。

注意：每个 TestFlight 构建只有 90 天有效期，过期后我会重新上传一版，你在 TestFlight 里更新即可；测试期间数据仍保存在本机，卸载才会清空。
