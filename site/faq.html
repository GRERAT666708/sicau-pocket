安装与更新

APK 怎么装？提示"未知来源"会不会有风险？

在「下载」页点下载，得到 sicau-pocket-latest.apk。系统会提示"禁止安装未知来源应用"，在弹窗里允许你用的浏览器（或文件管理器）安装即可。安装包由本机的构建脚本产出，源码在 GitHub 开源，你也可以自己构建比对。

新版本要卸载重装吗？

不用。直接覆盖安装即可，课表、学期备份、专注记录、绑定信息都会保留（除非签名变化，那需要先卸载——本项目签名固定，不会出现）。

为什么只有 arm64 的包？

目前只发布 arm64 版本，覆盖近几年绝大多数安卓手机。如果你的设备是 32 位老机型，装不上，可以发邮件告诉我机型，我补一个 armeabi-v7a 包。

课表相关

怎么导入我自己的课表？

课表页右下角「+」→「教务课表导入」，会打开学校教务系统的登录页（校外会走校园 VPN）。登录后进到"我的课表/课表查询"，点底部「导入这个页面」即可。也可以在「我的 → 教务课表导入」进入，支持账号导入、粘贴课表链接、粘贴网页源码三种方式。

第一次打开看到的是示例课表？

是。全新安装时会放一份动物医学专业的示例课表，课表页顶部有提示条，点「去导入」就会换成你自己的。导入后示例课表会被替换，提示条也不再出现。

周次不对 / 显示未开学？

到「设置 → 学期与周次」改第 1 教学周周一和总周数。默认是 2026-09-07 开学、共 18 周。也可以从「设置 → 学期管理与备份」新建学期。

课表那一格三行小字太小了？

为了把 7 天放进一屏，每列只有约 41dp，三行分别是课名、教室、老师。如果你更看重可读性，可以在设置里等后续版本切到"每天 2 列宽"的模式（正在做）。

数据与隐私

要注册账号吗？会上传我的课表吗？

不需要注册；不上传。App 没有服务器，课表、专注记录、绑定信息都存在手机本地。详见 隐私政策。

换手机 / 重装后数据还在吗？

不在。请在「学期管理与备份」里保留历史学期，或对重要页面截图留档。我们不提供云端备份。

卸载后你们那边还有我的数据吗？

没有。我们这边从来没有你的数据副本，卸载即全部清除。

功能相关

空闲教室的数据从哪来？准吗？

来自教务处「教室课表」的公开页面：先同步教室总表（211 间），再按楼栋抓每间教室整学期的课表，缓存在本机 7 天。它是学校排课数据，能反映正常课程占用，但不包括临时借用的活动、考试、调课，实际去之前建议门口看一眼。

成绩查询是怎么实现的？安全吗？

在 App 内置浏览器里登录教务，进到成绩页面，点底部「导入这个页面」，App 读取页面上已经显示的成绩表格并保存到本机。密码在学校的网页里输入，App 不读取、不保存。

宿舍电费余额怎么来的？为什么点进去是学校的页面？

电费充值在一卡通（智慧川农）的 H5 里，App 没有官方接口，所以做法是：你把微信里的一卡通链接（带 openid）粘贴绑定一次，之后 App 用内置浏览器打开学校的电费页，读出你选过的房间与余额显示在主页。充值仍在学校的页面里完成。选错宿舍可以在校园卡页点「重新选宿舍」清掉重选。

桌面小组件怎么加？

长按桌面空白处 → 小组件 → 找到「川农口袋」，可选 4×2 今天课表或 2×2 下一节课。数据在打开 App 时同步，点小组件上的「刷新」可立即更新。

支持深色模式吗？

支持，默认跟随系统。也可以在「设置 → 外观」里固定为浅色或深色。
